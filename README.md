# Contexo

> **Preview.** This extension is in early development. Commands, views and settings may change between releases.

Contexo brings a Contexo knowledge base into VS Code: page changes in the Source Control view, a Knowledge view of the project's pages, and push, pull and conflict resolution, all driven by the `ctx` command-line tool.

## Requirements

- The Contexo CLI, `ctx`, installed on this machine. Installation and login are covered in the [Contexo documentation](https://docs.contexo.live).
- VS Code 1.100 or later.
- A folder initialized for Contexo (it contains `.contexo/config.json`).
